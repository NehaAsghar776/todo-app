\# To-Do List Laravel App



\## Description

A To-Do List Management Web Application built with Laravel framework featuring secure authentication through Laravel Breeze and an interactive dashboard with graphical reports.

\## Features

\- User Registration and Login (Laravel Breeze)

\- Dashboard with Statistics (Total, Completed, Pending Tasks)

\- Pie Chart and Bar Chart for task visualization

\- Add, Complete, and Delete Tasks

\- Tasks Table with Status and Date



\## Technologies Used

\- Laravel 12

\- Laravel Breeze (Authentication)

\- Blade Templates

\- Chart.js

\- SQLite Database
